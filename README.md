# 🤖 LLM Evaluation and Bias Detection Framework

## Overview
A Streamlit-based application that evaluates Large Language Model (LLM) responses for:
- Bias Detection
- Toxicity Detection
- Factual Accuracy
- Hallucination Risk
- Overall Safety Score

## Features
- Detects biased language
- Detects toxic content
- Verifies factual accuracy using Wikipedia
- Estimates hallucination risk
- Generates overall safety score
- Saves evaluation reports as CSV
- Interactive dashboard with graphs

## Tech Stack
- Python
- Streamlit
- Pandas
- Matplotlib
- Wikipedia API
- Git & GitHub
